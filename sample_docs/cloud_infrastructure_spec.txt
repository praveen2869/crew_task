CLOUD INFRASTRUCTURE ARCHITECTURE SPECIFICATION
Document Reference: SPEC-CLOUD-INFRA-8839
Status: Approved for Production
Revision: 4.1.0
Last Updated: March 2025

SECTION 1: NETWORKING & VPC TOPOLOGY
The production platform is hosted in AWS us-east-1 and us-west-2 multi-region active-passive clusters.
- Primary VPC CIDR block: 10.100.0.0/16
- Secondary / Failover VPC CIDR block: 10.200.0.0/16
- Public Subnets: 10.100.1.0/24, 10.100.2.0/24 (NAT Gateways and Application Load Balancers)
- Private Subnets (App Tier): 10.100.10.0/24, 10.100.20.0/24
- Isolated Database Subnets: 10.100.50.0/24, 10.100.60.0/24 (No direct egress to public internet)

SECTION 2: VECTOR DATABASE & SEARCH ENGINE (QDRANT)
The vector search layer uses a distributed Qdrant cluster deployed on Kubernetes:
- Replica Count: 3 nodes running in high-availability consensus mode (Raft).
- Service Endpoints: Internal gRPC on port 6334, REST API on port 6333.
- Resource Allocations: 16 GB RAM and 4 vCPU allocated per Qdrant pod.
- Persistence: 500 GB NVMe gp3 EBS volumes mounted at /qdrant/storage with 10,000 provisioned IOPS.
- Indexing Topology: HNSW indexing with m=16, ef_construct=128, and cosine distance metric.
- Backup Frequency: Automated snapshot backups taken every 6 hours and replicated to AWS S3 Glacier.

SECTION 3: APPLICATION TIER & FASTAPI GATEWAY
- The backend API runs FastAPI microservices under Uvicorn with Gunicorn process management.
- Container base image: Python 3.11-slim on Alpine/Debian Linux.
- Auto-scaling Policy: Horizontal Pod Autoscaler scales pods between 3 and 15 replicas based on CPU target of 70% or P95 request latency exceeding 350ms.
- Health Check Probe: HTTP GET /api/v1/health with initial delay of 10s, probe period of 15s, and failure threshold of 3.

SECTION 4: CACHING & MESSAGE BROKER
- In-memory caching uses Redis Cluster version 7.2.
- Default Cache TTL: 3,600 seconds (1 hour) for retrieved embedding results and 86,400 seconds (24 hours) for static document summaries.
- Eviction Policy: volatile-lru (Least Recently Used with expiration timestamp).

SECTION 5: SECURITY & CERTIFICATE ROTATION
- All external traffic terminates at AWS ALB with TLS 1.3 encryption.
- SSL/TLS wildcard certificates (*.acme-corp.internal) are automatically renewed via Let's Encrypt ACME protocol every 90 days.
- In-cluster mTLS is enforced using Istio service mesh with SPIFFE/SPIRE cryptographic identities.
